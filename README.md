# 🐍 Python Mini Projeler

Python öğrenirken yazdığım küçük projeler.

| Dosya | Açıklama |
|---|---|
| [`metinden_sese.py`](metinden_sese.py) | Tkinter arayüzüyle girilen Türkçe metni **gTTS** ile sese çevirip oynatır |
| [`sifre_olusturucu.py`](sifre_olusturucu.py) | `secrets` modülüyle güvenli rastgele şifre üretir |
| [`rastgele_sayi.py`](rastgele_sayi.py) | `random` modülüyle tam sayı ve ondalıklı rastgele sayı üretme örnekleri |

## Kurulum

```bash
pip install gtts pygame   # yalnızca metinden_sese.py için gerekli
```

## Çalıştırma

```bash
python3 metinden_sese.py
python3 sifre_olusturucu.py -u 20
python3 rastgele_sayi.py
```
